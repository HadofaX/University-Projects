# Image Puzzle App

A desktop image puzzle game built with **C# Windows Forms**. Users load an image, shuffle its pieces, and solve the puzzle by selecting and swapping two pieces at a time.

## Features

- Load an image from the computer.
- Split the image into a **4 × 4 grid** (16 pieces).
- Shuffle the puzzle pieces.
- Select and swap two pieces to restore the original image.
- Preview the original image.
- Track the number of moves and elapsed time.
- Display a success message when the puzzle is solved.

## How to Play

1. Click **Load Image** and choose an image.
2. Click **Shuffle** to mix the pieces and start the timer.
3. Select one piece, then select another piece to swap their positions.
4. Continue until the original image is restored.
5. Use **Reset** to return the pieces to their original order.

## Technologies

- C#
- .NET Windows Forms
- Visual Studio

## Run the Project

1. Open `Image Puzzle App.sln` in Visual Studio.
2. Build the solution.
3. Run the application.

## Project Purpose

This project demonstrates image handling, bitmap processing, grid-based interface design, event-driven programming, and basic game-state tracking in Windows Forms.
