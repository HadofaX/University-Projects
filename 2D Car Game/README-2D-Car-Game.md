# 2D Car Game

A simple 2D racing game built with **C# Windows Forms**. The player controls a car, avoids incoming traffic, and tries to achieve the highest score.

## Features

- Player car movement with smooth left/right controls.
- Multiple opponent cars and obstacle avoidance.
- Score tracking during gameplay.
- Game Over screen when the player collides with an obstacle.
- Restart the game by pressing **Enter**.

## Controls

| Key | Action |
|---|---|
| Left Arrow / A | Move left |
| Right Arrow / D | Move right |
| Enter | Restart after Game Over |

## Technologies

- C#
- .NET Windows Forms
- Visual Studio

## Run the Project

1. Open `Game2DCar.sln` in Visual Studio.
2. Build the solution.
3. Run the application.

Keep the `Assets` folder alongside the project files because it contains the car images used by the game.

## Project Purpose

This project demonstrates basic game development concepts, including keyboard input, timers, collision detection, score handling, and drawing a simple racing environment.
